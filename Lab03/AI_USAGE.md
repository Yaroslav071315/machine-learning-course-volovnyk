# Декларація про використання штучного інтелекту (AI Usage Statement)

Під час виконання цієї лабораторної роботи використовувалися інструменти штучного інтелекту (LLM) для розробки коду, візуалізації та формування теоретичних пояснень.

### Сфери застосування ШІ:
1. **Генерація та оптимізація коду:**
   - Побудова сіток гіперпараметрів для `GridSearchCV` (Linear та RBF SVM).
   - Візуалізація результатів: створення теплових карт (`seaborn.heatmap`) та графіків із двома осіми $Y$ (`twinx`) для експерименту з розмірністю.
   - Алгоритм обчислення співвідношення мінімальної та максимальної евклідової відстаней ($d_{min}/d_{max}$) через `scipy.spatial.distance.pdist`.
2. **Аналітичне та теоретичне обґрунтування:**
   - Опис фізичного змісту параметрів $C$ та $\gamma$ у SVM, закономірностей зміни кількості опорних векторів.
   - Математичне пояснення феномену "концентрації відстаней" (*Distance Concentration Phenomenon*) у високорозмірних просторах.
3. **Оформлення документації:**
   - Форматування Markdown-структури для Jupyter Notebook, `README.md` та `AI_USAGE.md`.

### Контроль та відповідальність:
Усі згенеровані рішення були протестовані, перевірені на відсутність витоку даних (Data Leakage) та сумісність із вимогами завдання. Автор повністю розуміє реалізовану логіку та відповідає за результат.
