# AI_USAGE.md

## Використання генеративного ШІ

Генеративний ШІ використовувався як допоміжний інструмент під час підготовки розділів 1–2 роботи для набору **UCI Hill-Valley**.

### Використані задачі

1. Опрацьовано опис набору даних Hill-Valley з UCI.
2. Сформульовано прикладну постановку бінарної класифікації Hill/Valley.
3. Сформульовано перевірювані гіпотези щодо:
   - впливу масштабування;
   - метрики відстані та способу голосування KNN;
   - Linear SVM проти RBF SVM.
4. Запропоновано структуру експерименту: train/test split, StratifiedKFold, метрики та сітки гіперпараметрів.
5. Підготовлено текстове оформлення README та Notebook.

### Перевірка

Опис датасету, кількість ознак, класи та наявність missing values перевірені за офіційною сторінкою UCI Hill-Valley. Остаточні метрики моделей, результати CV та test results не генеруються ШІ наперед — вони повинні бути отримані фактичним запуском Notebook.

### Джерело

UCI Machine Learning Repository — Hill-Valley, dataset ID 166:
https://archive.ics.uci.edu/dataset/166/hill+valley


# Декларація про використання штучного інтелекту (AI Usage Statement)

1. **Генерація коду:** ШІ був використаний для створення бойлерплейт-коду (boilerplate) бібліотеки `scikit-learn` для побудови пайплайнів (`Pipeline`, `ColumnTransformer`), а також для генерації циклу візуалізації границь рішень (`DecisionBoundaryDisplay`).

**Відповідальність:**
Увесь згенерований код був перевірений мною на відповідність технічному завданню. Я повністю розумію логіку роботи `StandardScaler`, `Pipeline`, алгоритмів SVM та KNN, реалізованих у цьому проєкті, і несу відповідальність за фінальний результат роботи.

# ML Lab: Geometric Experiment, Scaling Study & Metric Classifiers

## Опис проєкту
Цей репозиторій містить виконання лабораторної/практичної роботи з машинного навчання, яка охоплює:
1. **Контрольний геометричний експеримент**: Візуалізація та аналіз впливу масштабування ознак на синтетичному датасеті `make_moons` для KNN, Linear SVM та RBF SVM.
2. **Підготовка даних**: Побудова препроцесингових пайплайнів (`Pipeline`, `ColumnTransformer`) із застосуванням `StandardScaler`, `MinMaxScaler` та `OneHotEncoder`.
3. **Дослідження масштабування**: Порівняльний аналіз моделей без scaler, зі `StandardScaler` та з `MinMaxScaler` на основі 5-fold cross-validation.
4. **Метричні класифікатори**: Налаштування та оцінка `NearestCentroid` та `KNeighborsClassifier` за сіткою гіперпараметрів ($k \in \{1, 3, 5, 7, 11\}$, $p \in \{1, 2\}$, `weights \in {'uniform', 'distance'}`).
