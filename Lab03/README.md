# Hill-Valley — експериментальне дослідження класифікації

> Поточний файл містить лише розділи 1–2 роботи.

## 1. Формулювання експериментальної задачі

### 1.1. Прикладна мета класифікації

Hill-Valley — бінарна задача класифікації. Кожен запис містить 100 точок графіка, які формують або Hill (підйом), або Valley (западину). Цільова змінна `class`: `0 = valley`, `1 = hill`. UCI також зазначає, що пропущених значень немає. [UCI Hill-Valley](https://archive.ics.uci.edu/dataset/166/hill+valley)

**Ознаки:** `X01 ... X100`  
**Цільова змінна:** `class`  
**Класи:** `Valley (0)`, `Hill (1)`

### 1.2. Важливі помилки

Обидва класи вважаються однаково важливими, оскільки в умові задачі не задано різної вартості помилок `Hill → Valley` та `Valley → Hill`.

Тому аналізуються confusion matrix, precision, recall та F1-score для обох класів.

### 1.3. Основна метрика

Основна метрика — **macro F1-score** (`f1_macro`). Вона однаково враховує якість класифікації Hill і Valley.

Додаткові метрики: accuracy, precision, recall, confusion matrix, training time та prediction time.

### 1.4. Перевірювані гіпотези

| Гіпотеза | Експеримент | Критерій підтвердження |
|---|---|---|
| **H1. StandardScaler покращує якість KNN та SVM.** | Порівняти моделі без масштабування та з `StandardScaler` за однаковою 5-fold Stratified CV. | Середній CV `f1_macro` з масштабуванням вищий щонайменше на **0.01**. |
| **H2. Метрика відстані та спосіб голосування впливають на KNN.** | Перевірити `euclidean/manhattan` та `uniform/distance` разом із різними `n_neighbors`. | Найкраща конфігурація KNN дає приріст CV `f1_macro` ≥ **0.01** відносно базової конфігурації. |
| **H3. RBF SVM забезпечує вищу якість, ніж Linear SVM.** | Порівняти Linear SVM і RBF SVM за однаковою CV та зафіксованими сітками. | Найкращий RBF має CV `f1_macro` ≥ на **0.01** вище за найкращий Linear SVM. |

## 2. Планування експерименту

| Параметр | Зафіксоване значення |
|---|---|
| Dataset | UCI Hill-Valley, ID 166 |
| Train/test split | 80% / 20% |
| Random state | 42 |
| CV | StratifiedKFold, 5 folds, shuffle=True |
| Основна метрика | `f1_macro` |
| Додаткові | accuracy, precision, recall, confusion matrix, time |
| Test set | відкривається один раз після пошуку |

### Кандидатні моделі

1. KNN
2. Linear SVM
3. RBF SVM

### Масштабування

- без масштабування;
- `StandardScaler` у Pipeline.

### Початкові сітки

**KNN:** `n_neighbors=[3,5,7,11,15]`, `weights=['uniform','distance']`, `metric=['euclidean','manhattan']` → **20 конфігурацій**.

**Linear SVM:** `C=[0.01,0.1,1,10,100]` → **5 конфігурацій**.

**RBF SVM:** `C=[0.1,1,10,100]`, `gamma=['scale',0.001,0.01,0.1]` → **16 конфігурацій**.

За двох варіантів масштабування кількість кандидатних запусків подвоюється.

### Правило вибору фінальної моделі

Фінальна модель визначається за максимальним середнім CV `f1_macro`. Якщо різниця між кандидатами менша за 0.01, додатково враховуються latency, training time, пам'ять та пояснюваність.

Test set відкривається **лише один раз після завершення пошуку** і не використовується для подальшого підбору параметрів.

### Зміна сітки

Якщо після першого запуску сітку змінено, початкові результати не видаляються. Нова сітка оформлюється як окрема перевірювана гіпотеза із причиною зміни та критерієм підтвердження.
