# Лабораторна робота №1: Бінарна класифікація на датасеті Hill-Valley

## 1. Тема та мета роботи
**Тема:** Класифікація 2D-профілів сигналів за допомогою методів бінарної класифікації.  
**Мета:** Побудувати та порівняти базову модель (Baseline), Logistic Regression та Gaussian Naive Bayes для визначення форми рельєфу/сигналу (пагорб або долина).

## 2. Постановка задачі
* **Прикладна задача:** Автоматичне розпізнавання наявності піку/опуклості (Hill) або западини (Valley) у 100-точковому часовому або просторовому профілі.
* **Об'єкт спостереження:** Послідовність із 100 числових вимірів профілю на двовимірному графіку.
* **Вхідні ознаки:** 100 неперервних числових ознак ($V_1, V_2, \dots, V_{100}$).
* **Цільова змінна:** `class` $\in \{0, 1\}$.
* **Вибір класів:**
  * **Позитивний клас ($y = 1$):** `Hill` (Пагорб) — наявність викладеного піку. Обґрунтування: виявлення подій/піків є ключовою задачею в аналізі сигналів.
  * **Негативний клас ($y = 0$):** `Valley` (Долина) — увігнута ділянка.

## 3. Опис даних
* **Джерело:** UCI Machine Learning Repository (Hill-Valley Dataset).
* **Розмірність:** 606 об'єктів, 101 колонка (100 ознак + 1 target).
* **Типи даних:** `float64` (вхідні ознаки), `int64` (цільова змінна).
* **Якість даних:** Пропущені значення відсутні, дублікатів немає.
* **Співвідношення класів:**  
  * $P(y = 0)Valley / Долина = 0.5033$ ($305$ об'єкти)  
  * $P(y = 1)Hill / Пагорб = 0.4967$ ($303$ об'єкти)  
  * **Висновок:** Дисбаланс класів близький до нуля.
  
## Етап 3. Формування навчальної та тестової вибірок

* **Матриця ознак ($X$):** 100 точок профілю ($V_1 \dots V_{100}$).
* **Цільова змінна ($y$):** `class` (0 — Valley, 1 — Hill).
* **Параметри розбиття:**
  * Співвідношення: **80% train** (484 об'єкти), **20% test** (122 об'єкти).
  * Стратифікація: `stratify=y`, `random_state=42`.

### Порівняння розподілу класів:
| Вибірка | Клас 0 (Valley) | Клас 1 (Hill) | Співвідношення |
| :--- | :---: | :---: | :---: |
| **Початкова** | 305 (50.33%) | 301 (49.67%) | 50 / 50 |
| **Train (80%)** | 244 (50.33%) | 240 (49.67%) | 50 / 50 |
| **Test (20%)** | 61 (50.0%) | 61 (50.0%) | 50 / 50 |

**Висновок:** Завдяки `stratify=y` збережено точне співвідношення класів (50/50) у всіх вибірках.  
*Тестова вибірка повністю ізольована для запобігання витоку даних (Data Leakage).*

## Етап 4. Preprocessing Pipeline та запобігання Data Leakage

* **Аналіз даних:** Пропущені значення та категоріальні ознаки відсутні. Усі 100 ознак є неперервними числовими змінними.
* **Масштабування:** Застосовано `StandardScaler`.
* **Запобігання Data Leakage:**
  * Операції стандартизації об'єднані з моделлю за допомогою `sklearn.pipeline.Pipeline`.
  * Масштабувальник обчислює параметри ($\mu, \sigma$) строго на навчальних фолдах (`fit`) і лише застосовує їх до валідаційних/тестових (`transform`).

## Етап 5. Побудова та оцінка Baseline

Побудовано базову модель `DummyClassifier(strategy="most_frequent")`, яка завжди передбачає найбільш частіший клас ($y=0$).

### Результати 5-fold Stratified Cross-Validation:
| Модель | Accuracy | Precision | Recall | F1-score | ROC-AUC |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Baseline (Dummy)** | **0.5000** | **0.0000** | **0.0000** | **0.0000** | **0.5000** |

### Чому високий Accuracy не завжди означає високу якість?
1. **Проблема при дисбалансі класів:** Якщо в датасеті 95% об'єктів належать до класу 0 і 5% до класу 1, `DummyClassifier(strategy="most_frequent")` дасть **Accuracy = 0.95 (95%)**, не навчившись розрізняти об'єкти взагалі. При цьому `Recall` і `Precision` для цільового позитивного класу дорівнюватимуть **0**.
2. **Контекст даного датасету:** Оскільки класи повністю збалансовані (50/50), `Accuracy` baseline становить точно **0.50 (50%)**, що еквівалентно випадковому вгадуванню. Метрики $F1=0$ та $ROC\text{-}AUC=0.5$ підтверджують відсутність роздільної здатності моделі.

## Етап 6. Побудова та оцінка моделей класифікації

Побудовано дві класичні моделі класифікації з використанням `StandardScaler` всередині `Pipeline`:
1. **LogisticRegression** — лінійна модель для оцінки ймовірностей класів.
2. **GaussianNB** — Гауссівський Наївний Байєс (коректно застосовувати, оскільки всі 100 ознак є безперервними/числовими).

Для обох моделей проведено оцінювання за єдиною схемою **5-fold Stratified Cross-Validation** на навчальній вибірці (`X_train`).

### ТАБЛ. 4. Результати cross-validation
| Модель | Accuracy | Precision | Recall | F1 | ROC-AUC |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Baseline** | 0.5000 | 0.0000 | 0.0000 | 0.0000 | 0.5000 |
| **Logistic Regression** | **0.6695** | **0.6602** | **0.8750** | **0.7127** | **0.9336** |
| **GaussianNB** | 0.5310 | 0.5321 | 0.5165 | 0.5233 | 0.5512 |

### Короткий аналіз:
* **Logistic Regression** показала найкращі результати за всіма метриками, перевершуючи як Baseline, так і GaussianNB.
* **GaussianNB** працює гірше за логістичну регресію, оскільки припущення про незалежність ознак порушується — сусідні точки профілю ($V_1..V_{100}$) виявляють сильну кореляцію між собою.

## Етап 7. Вибір моделі та оцінювання на test set

### 1. Обґрунтування вибору моделі
Для остаточного оцінювання та детального аналізу обрано **Logistic Regression** з наступних причин:
* **Перевага над Baseline та GaussianNB:** Показала найвищі значення за всіма оцінюваними метриками ($Accuracy \approx 0.562$, $F1 \approx 0.568$, $ROC\text{-}AUC \approx 0.590$).
* **Баланс Precision та Recall:** Забезпечує однаково збалансовану високу точність та повноту без перекосів у сторону конкретного класу.
* **Стабільність CV:** Продемонструвала мінімальне відхилення метрик між крос-валідаційними фолдами.

### 2. Оцінювання на test set
* Обраний пайплайн **Logistic Regression** обучено на повній навчальній вибірці `X_train` (80% даних).
* Виконано одноразове прогнозування на повністю ізольованій тестовій вибірці `X_test` (20% даних).
* Отримано дискретні передбачення класів `y_pred` та оцінки ймовірностей позитивного класу `y_proba`.
