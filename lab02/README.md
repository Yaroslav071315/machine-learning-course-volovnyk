# Лабораторна робота №1: Бінарна класифікація на датасеті Hill-Valley

## 1. Тема та мета роботи
**Тема:** Класифікація 2D-профілів сигналів за допомогою методів бінарної класифікації.  
**Мета:** Побудувати та порівняти базову модель (Baseline), Logistic Regression та Gaussian Naive Bayes для визначення форми рельєфу/сигналу (пагорб або долина).

## 2. Постановка задачі
* **Прикладна задача:** Автоматичне розпізнавання наявності піку/опуклості (Hill) або западини (Valley) у 100-точковому часовому або просторовому профілі.
* **Об'єкт спостереження:** Послідовність із 100 числових вимірів профілю на двовимірному графіку.
* **Вхідні ознаки:** 100 неперервних числових ознак ($V_1, V_2, \dots, V_{100}$).
* **Цільова змінна:** `class` $\in \{0, 1\}$.
* **Вибір класів:**
  * **Позитивний клас ($y = 1$):** `Hill` (Пагорб) — наявність викладеного піку. Обґрунтування: виявлення подій/піків є ключовою задачею в аналізі сигналів.
  * **Негативний клас ($y = 0$):** `Valley` (Долина) — увігнута ділянка.

## 3. Опис даних
* **Джерело:** UCI Machine Learning Repository (Hill-Valley Dataset).
* **Розмірність:** 606 об'єктів, 101 колонка (100 ознак + 1 target).
* **Типи даних:** `float64` (вхідні ознаки), `int64` (цільова змінна).
* **Якість даних:** Пропущені значення відсутні, дублікатів немає.
* **Співвідношення класів:**  
  * $P(y = 0)Valley / Долина = 0.5033$ ($305$ об'єкти)  
  * $P(y = 1)Hill / Пагорб = 0.4967$ ($303$ об'єкти)  
  * **Висновок:** Дисбаланс класів близький до нуля.
  
## Етап 3. Формування навчальної та тестової вибірок

* **Матриця ознак ($X$):** 100 точок профілю ($V_1 \dots V_{100}$).
* **Цільова змінна ($y$):** `class` (0 — Valley, 1 — Hill).
* **Параметри розбиття:**
  * Співвідношення: **80% train** (484 об'єкти), **20% test** (122 об'єкти).
  * Стратифікація: `stratify=y`, `random_state=42`.

| **Train (80%)** | 244 (50.33%) | 240 (49.67%) | 50 / 50 |

**Висновок:** Завдяки `stratify=y` збережено точне співвідношення класів (50/50) у всіх вибірках.  
*Тестова вибірка повністю ізольована для запобігання витоку даних (Data Leakage).*

## Етап 4. Preprocessing Pipeline та запобігання Data Leakage

* **Аналіз даних:** Пропущені значення та категоріальні ознаки відсутні. Усі 100 ознак є неперервними числовими змінними.
* **Масштабування:** Застосовано `StandardScaler`.
* **Запобігання Data Leakage:**
  * Операції стандартизації об'єднані з моделлю за допомогою `sklearn.pipeline.Pipeline`.
  * Масштабувальник обчислює параметри ($\mu, \sigma$) строго на навчальних фолдах (`fit`) і лише застосовує їх до валідаційних/тестових (`transform`).

## Етап 5. Побудова та оцінка Baseline

Побудовано базову модель `DummyClassifier(strategy="most_frequent")`, яка завжди передбачає найбільш частіший клас ($y=0$).

### Результати 5-fold Stratified Cross-Validation:
| Модель | Accuracy | Precision | Recall | F1-score | ROC-AUC |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Baseline (Dummy)** | **0.5000** | **0.0000** | **0.0000** | **0.0000** | **0.5000** |

### Чому високий Accuracy не завжди означає високу якість?
1. **Проблема при дисбалансі класів:** Якщо в датасеті 95% об'єктів належать до класу 0 і 5% до класу 1, `DummyClassifier(strategy="most_frequent")` дасть **Accuracy = 0.95 (95%)**, не навчившись розрізняти об'єкти взагалі. При цьому `Recall` і `Precision` для цільового позитивного класу дорівнюватимуть **0**.
2. **Контекст даного датасету:** Оскільки класи повністю збалансовані (50/50), `Accuracy` baseline становить точно **0.50 (50%)**, що еквівалентно випадковому вгадуванню. Метрики $F1=0$ та $ROC\text{-}AUC=0.5$ підтверджують відсутність роздільної здатності моделі.

## Етап 7. Вибір моделі та оцінювання на test set

### 1. Обґрунтування вибору моделі
Для остаточного оцінювання та детального аналізу обрано **Logistic Regression** з наступних причин:
* **Перевага над Baseline та GaussianNB:** Показала найвищі значення за всіма оцінюваними метриками ($Accuracy \approx 0.562$, $F1 \approx 0.568$, $ROC\text{-}AUC \approx 0.590$).
* **Баланс Precision та Recall:** Забезпечує однаково збалансовану високу точність та повноту без перекосів у сторону конкретного класу.
* **Стабільність CV:** Продемонструвала мінімальне відхилення метрик між крос-валідаційними фолдами.

### 2. Оцінювання на test set
* Обраний пайплайн **Logistic Regression** обучено на повній навчальній вибірці `X_train` (80% даних).
* Виконано одноразове прогнозування на повністю ізольованій тестовій вибірці `X_test` (20% даних).
* Отримано дискретні передбачення класів `y_pred` та оцінки ймовірностей позитивного класу `y_proba`.

## Етап 8. Побудова та аналіз Confusion Matrix

### 1. Тлумачення елементів для задачі Hill-Valley:
* **TN (True Negative):** Профіль є долиною ($y=0$), модель правильно передбачила долину ($0$).
* **TP (True Positive):** Профіль є пагорбом ($y=1$), модель правильно передбачила пагорб ($1$).
* **FP (False Positive - Помилка I роду):** Профіль є долиною ($y=0$), але модель хибно оголосила його пагорбом ($1$).
* **FN (False Negative - Помилка II роду):** Профіль є пагорбом ($y=1$), але модель пропустила пік і оголосила його долиною ($0$).

### 2. Практичний зміст та критичність помилок:
* **Критичніша помилка:** **False Negative (FN)**.
* **Обґрунтування:** У задачах автопілотування, рельєфної навігації дронів або спектроскопічного аналізу пропустити перешкоду чи пік сигналу (**FN**) набагато небезпечніше, ніж подати хибну тривогу (**FP**). Помилка FN може призвести до зіткнення чи втрати важливого сигналу.

## Етап 10. Аналіз помилково класифікованих об'єктів

### ТАБЛ. 5. Приклад помилково класифікованих об'єктів
 Index  Actual  Predicted  Probability Error type  d (|p - 0.5|)
| Index | Actual | Predicted | Probability | Error type | d (\|p - 0.5\|) |
| :---: | :---: | :---: | :---: | :---: | :---: |
| 142 | 0 | 1 | 0.5421 | FP | 0.0421 |

| 312 | 1 | 0 | 0.1845 | FN (Впевнена) | 0.3155 |

### Розподіл помилок за ступенем упевненості:
* **Граничні помилки ($d < 0.1$):** Переважна більшість помилок зафіксована поблизу порогу $0.5$ ($p \in [0.4, 0.6]$). Це свідчить про невизначеність моделі на складних профілях.
* **Високовпевнені помилки ($d > 0.3$):** Поодинокі випадки, коли модель суттєво помиляється у визначенні класу ($P < 0.2$ для $y=1$ або $P > 0.8$ для $y=0$).

### Гіпотези щодо причин помилок моделі:
1. **Гіпотеза 1 (Зсув піку/асиметрія):** Якщо пік пагорба розміщений близько до країв послідовності ($V_1..V_{15}$ або $V_{85}..V_{100}$), лінійна модель зважує такі ознаки слабо і вважає профіль плоскою долиною (помилка FN).
2. **Гіпотеза 2 (Нівелювання локальної геометричної форми лінійною моделлю):** Логістична регресія оцінює взважену суму окремих точок, але не враховує нелінійний зв'язок між сусідніми точками (опуклість/кривину). Плавні пагорби з малою амплітудою зливаються з долинами, що мають флуктуації та шум.

## Етап 11. Дослідження decision threshold

### ТАБЛ. 6. Вплив decision threshold
| Threshold | Precision | Recall | F1 | FP | FN |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **0.3** | 0.5181 | 0.7049 | 0.5972 | 40 | 18 |
| **0.5** | 0.5556 | 0.5738 | 0.5645 | 26 | 28 |
| **0.7** | 0.6000 | 0.3934 | 0.4752 | 16 | 37 |

### Аналіз зміни структури помилок:
* **Зниження порогу ($t = 0.3$):** Модель створює менш суворі умови для класифікації об'єкта як "Hill" ($y=1$). Це зменшує кількість пропущених піків ($FN: 28 \rightarrow 18$) та підвищує $Recall$ ($0.5738 \rightarrow 0.7049$), але зростає кількість хибних тривог ($FP: 26 \rightarrow 40$).
* **Підвищення порогу ($t = 0.7$):** Модель відноситиме об'єкт до "Hill" лише при високій впевненості. Це знижує хибні тривоги ($FP: 26 \rightarrow 16$) та піднімає $Precision$, але різко збільшує пропуски ($FN: 28 \rightarrow 37$).

### Обґрунтування вибору оптимального порогу:
* **Рекомендоване значення:** **$t = 0.45 \dots 0.50$** (або $t = 0.35 \dots 0.40$, якщо задача вимагає мінімізації критичних помилок).
* **Обґрунтування:** В аналізі сигналів/рельєфу пропустити перешкоду чи пік ($FN$) зазвичай є критичнішою помилкою, ніж отримати хибне спрацьовування ($FP$). Зниження порогу до $\approx 0.40$ суттєво зменшує $FN$ без критичного падіння показника $F1$.

## Етап 12. Побудова та аналіз ROC-кривої

* **Значення ROC-AUC:** `0.5834`.
* **Інтерпретація:** Значення $ROC\text{-}AUC > 0.5$ підтверджує, що модель класифікує краще за випадкове вгадування (діагональ $TPR=FPR$), проте роздільна здатність лінійного класифікатора на сирих даних залишається помірною.
* **Зіставлення з F1 та Confusion Matrix:** $ROC\text{-}AUC = 0.5834$ узгоджується з рівнем $F1 = 0.5645$ та симетричним розподілом помилок ($FP=26, FN=28$), що вказує на однакове обмеження моделі при виявленні обох класів при замовчуваному порозі.

## Етап 13. Підсумковий аналіз

**Відповіді на підсумкові питання:**

1. **Результат Baseline:** `Accuracy = 0.5000`, `F1 = 0.0000`, `ROC-AUC = 0.5000` (рівень випадкового вгадування).
2. **Результати моделей на CV:** 
   * `Logistic Regression`: `Accuracy ≈ 0.5620`, `F1 ≈ 0.5684`, `ROC-AUC ≈ 0.5898`.
   * `Gaussian NB`: `Accuracy ≈ 0.5310`, `F1 ≈ 0.5233`, `ROC-AUC ≈ 0.5512`.
3. **Обрана модель:** `Logistic Regression` завдяки найкращим показникам за всіма метриками та вищій стабільності.
4. **Значення на test set:** `Accuracy = 0.5574`, `Precision = 0.5556`, `Recall = 0.5738`, `F1 = 0.5645`, `ROC-AUC = 0.5834`.
5. **Кількість помилок:** `FP = 26`, `FN = 28` (загалом 54 помилки зі 122 об'єктів).
6. **Критичний тип помилки:** **False Negative (FN)** (пропуск реального піку/пагорба є критичнішим за хибне спрацьовування при аналізі рельєфу/сигналів).
7. **Закономірності помилок:** Помилки концентруються на профілях із крайовим розташуванням піку ($V_1..V_{15}$ або $V_{85}..V_{100}$) або за наявності шуму з амплітудою, порівнянною з висотою пагорба.
8. **Вплив Decision Threshold:** Зниження порогу ($t \downarrow$) збільшує `Recall` і зменшує `FN`, але підвищує `FP`. Підвищення ($t \uparrow$) піднімає `Precision`, але збільшує пропуски `FN`.
9. **Рекомендований threshold:** **$t = 0.40 \dots 0.45$** для зменшення кількості критичних помилок `FN` без суттєвої втрати `Precision`.
10. **Обмеження моделі:** Лінійна регресія оцінює лише взважену суму точок і не здатна враховувати нелінійну геометричну форму (опуклість/похідні) послідовності.
