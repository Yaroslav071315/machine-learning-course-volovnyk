# Використання генеративного ШІ (AI Usage)

Під час виконання цієї лабораторної роботи генеративний штучний інтелект використовувався для наступних завдань:

1. **Формулювання прикладної задачі:** Допомога у перетворенні технічної задачі ("спрогнозувати стовпець `sepal_width`") на логічно обґрунтований прикладний кейс (ботанічна морфометрія, цифрова реконструкція зразків, біоіндикація) відповідно до вимог оформлення.
2. **Структурування документації:** Форматування тексту та створення шаблонів для файлів `README.md` та `AI_USAGE.md` із дотриманням необхідної структури проєкту (Тема, Постановка задачі, План експерименту).
3. **Оформлення Markdown:** Розмітка та логічне групування тексту для інтеграції у клітини Jupyter Notebook.
4. **Первинний аналіз даних (EDA):** Генерація Python-коду (бібліотеки `pandas`, `seaborn`) для розрахунку базових статистик, перевірки пропусків/дублікатів та візуалізації розподілу цільової змінної `sepal_width` у розрізі категорій.
5. **Планування експерименту:** Допомога у формулюванні методологічно правильного плану машинного навчання: вибір стратегії 5-Fold крос-валідації через малий обсяг датасету, обґрунтування метрик (RMSE та $R^2$) та вибір репрезентативної Baseline-моделі (`DummyRegressor`).
6. **Налаштування Pipeline:** Використання LLM для створення синтаксично правильного коду `ColumnTransformer`, який паралельно застосовує `StandardScaler` до числових колонок та `OneHotEncoder` до категоріальних.
7. **Формулювання обґрунтувань:** Допомога у написанні чіткого пояснення методології (чому відмова від видалення дублікатів є правильною в контексті біометричних вимірювань квіток).
8. **Оцінка Baseline-моделі:** Генерація коду для підключення `DummyRegressor` до пайплайну та розрахунку метрик `neg_root_mean_squared_error` і `r2` через функцію `cross_validate`.
9. **Написання коду для крос-валідації:** Використання ШІ для правильної організації процесу `cross_validate` з передачею об'єктів `Pipeline`, щоб запобігти витоку даних на етапі стандартизації ознак.
10. **Оптимізація гіперпараметрів:** Генерація коду `GridSearchCV` для автоматизованого пошуку найкращого коефіцієнта `alpha` для Ridge-регресії та вилучення метрик (`mean_test_score`, `std_test_score`) найкращої моделі з атрибута `cv_results_`.
11. **Візуалізація результатів:** Допомога у побудові графіка `barplot` за допомогою `seaborn` із додаванням кастомних "вусів" (error bars) на основі розрахованих стандартних відхилень RMSE для порівняння стабільності моделей.
12. **Фінальне тестування:** Генерація коду для застосування навченого пайплайну до тестової вибірки та комплексного розрахунку фінальних метрик (MAE, RMSE, $R^2$) через функцію користувача.
13. **Візуалізація якості передбачень:** Написання коду (matplotlib) для побудови Scatter-графіків "$Y_{true}$ vs $Y_{predicted}$" з ідеальною діагоналлю, а також графіка залишків (Residuals Plot) з горизонтальною віссю симетрії.
14. **Аналіз похибок:** Написання логіки Pandas (`nlargest`) для автоматичного пошуку 5 індексів із найбільшою абсолютною різницею між прогнозом та фактом. Використання ШІ для генерування біологічно обґрунтованого пояснення причин появи таких похибок (природна дисперсія, перехрещення видових ознак).
15. **Формулювання обґрунтування:** Використання генеративного ШІ для синтезу логічного обґрунтування вибору моделі (Ridge), що базується на сукупності факторів (стабільність CV, інтерпретованість, аналіз залишків), а не лише на одній метриці.
16. **Структурування висновків:** Допомога у лаконічному та вичерпному формулюванні відповідей на 9 обов'язкових питань для фінального звіту з дотриманням наукового стилю викладу.
