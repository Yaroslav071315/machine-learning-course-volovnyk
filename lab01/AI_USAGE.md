# Використання генеративного ШІ (AI Usage)

Під час виконання цієї лабораторної роботи генеративний штучний інтелект використовувався для наступних завдань:

1. **Формулювання прикладної задачі:** Допомога у перетворенні технічної задачі ("спрогнозувати стовпець `sepal_width`") на логічно обґрунтований прикладний кейс (ботанічна морфометрія, цифрова реконструкція зразків, біоіндикація) відповідно до вимог оформлення.
2. **Структурування документації:** Форматування тексту та створення шаблонів для файлів `README.md` та `AI_USAGE.md` із дотриманням необхідної структури проєкту (Тема, Постановка задачі, План експерименту).
3. **Оформлення Markdown:** Розмітка та логічне групування тексту для інтеграції у клітини Jupyter Notebook.
