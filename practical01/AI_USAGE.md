# AI_USAGE.md

Короткий опис використання генеративного ШІ під час виконання цієї роботи.

- **Інструмент:** Claude (Anthropic).
- **Що саме було зроблено за допомогою ШІ:**
  - Побудова структури звіту `README.md` відповідно до вимог методичних вказівок.
  - Написання коду для завантаження набору даних Iris (`sklearn.datasets.load_iris`) та проведення первинного аудиту (`df.head()`, `df.shape`, `df.info()`, `df.dtypes`, `df.nunique()`, `df.isnull().sum()`, `df.duplicated().sum()`).
  - Формулювання текстових пояснень до кожного кроку аудиту та відповідей на пункти постановки задачі (джерело даних, предметна область, тип задачі, практичний зміст прогнозування).
- **Що зроблено самостійно / потребує перевірки:**
  - Числові результати аудиту (розмірність, кількість унікальних значень, кількість дублікатів тощо) отримані шляхом реального виконання коду в Jupyter-ноутбуці, а не згенеровані ШІ "на слово" — усі наведені в звіті цифри відповідають фактичному виводу комірок ноутбука.
  - Перед здачею роботи рекомендується самостійно повторно виконати ноутбук (`Kernel → Restart & Run All`) та звірити результати, а також заповнити персональні дані (ПІБ, група) у заголовку звіту.
- **Обмеження:** ШІ не використовувався для побудови моделі машинного навчання — відповідно до умови завдання, модель на цьому етапі роботи не будується.
