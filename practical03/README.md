# Iris Dataset — прогнозування `Sepal width`

## 1. Тема та мета роботи

Дослідити залежність між складністю поліноміальної регресії та якістю узагальнення для Iris Dataset, виявити недонавчання/перенавчання та перевірити вплив регуляризації на складному просторі ознак.

## 2. Постановка задачі

Тип задачі — регресія. Цільова змінна — `Sepal width (cm)`. Для прогнозування використовуються `Sepal length`, `Petal length`, `Petal width`.

## 3. Опис даних

Iris містить 150 спостережень і 4 числові вимірювання. Цільова змінна одна, тому в моделі використовуються 3 числові предиктори. Категоріальні ознаки відсутні. Пропуски перевіряються перед експериментами.

## 4. Експериментальний протокол

| Параметр | Значення |
|---|---|
| Train/Test | 80% / 20% |
| `random_state` | 42 |
| CV | 5-fold `KFold(shuffle=True, random_state=42)` |
| Основна метрика | RMSE |
| Початковий Pipeline | `PolynomialFeatures → StandardScaler → estimator` |
| Шкала складності | degree 1–10 |
| Ridge alpha (зафіксовано в порівнянні) | 0.1 |
| Lasso alpha | 0.001 |
| Elastic Net alpha | 0.001 |
| Elastic Net `l1_ratio` | 0.7 |

Протокол був зафіксований до перегляду основних результатів. Повна сітка alpha/l1_ratio з попереднього етапу не змішується з контрольованим порівнянням типів регуляризації в пункті 6.

## 5. Перевірювані гіпотези

**H1:** зі зростанням degree train RMSE зменшується, але CV RMSE після певного оптимального рівня зростає. Підтвердженням є наявність мінімуму CV RMSE та подальшого погіршення.

**H2:** на високих ступенях зростає generalization gap `CV RMSE − Train RMSE`. Підтвердженням є одночасне зростання gap і CV RMSE.

**H3:** регуляризація покращує узагальнення складної моделі. Покращення визначається як менший CV RMSE; за близьких значень — менший generalization gap, менший CV RMSE std та/або простіша модель.

## 6. Контрольована шкала складності

Оскільки після вибору цілі залишається 3 числові ознаки, кількість ознак для `PolynomialFeatures(degree=d, include_bias=False)` обчислюється до запуску:

`N(d) = C(3+d, d) − 1`.

Для degree=1–10 отримуємо від 3 до 285 ознак. Оціночний розмір однієї dense `float64` train-матриці для максимуму є малим, тому всі конфігурації можна безпечно запускати на цьому наборі.

## 7. Діагностика недонавчання та перенавчання

Результати для кожного degree містять mean train RMSE, mean CV RMSE, CV RMSE std, стандартну похибку середнього, generalization gap, кількість поліноміальних ознак та час CV.

Графіки:

- `figures/01_complexity_train_vs_cv_rmse.png`
- `figures/02_generalization_gap.png`

Для Iris найкраща область узагальнення знаходиться на низьких ступенях; після неї train RMSE продовжує падати, а CV RMSE і gap різко погіршуються. Це узгоджується з ознаками перенавчання.

## 8. Криві навчання

Побудовано learning curves для:

- degree=1 — модель низької складності;
- degree=10 — модель із найвираженішим перенавчанням.

Показуються train RMSE і CV RMSE, а для CV — смуги ±1 std. Через різницю похибок на кілька порядків використовується логарифмічна шкала Y.

Графік: `figures/05_learning_curves.png`.

Інтерпретація: для degree=1 криві відносно близькі, тому простій моделі насамперед бракує ємності. Для degree=10 train RMSE дуже мала, а CV RMSE значно більша, тому основна рекомендація — зменшити складність або застосувати регуляризацію; додаткові дані можуть зменшити gap, але не є першим виправленням.

## 9. Застосування регуляризації

Для всіх чотирьох моделей використано **один і той самий простір `PolynomialFeatures(degree=10)`**, однаковий `StandardScaler`, однаковий 5-fold CV і RMSE:

- Linear Regression;
- Ridge;
- Lasso;
- Elastic Net.

Попередження про збіжність не приховуються. Для Elastic Net задано `max_iter=300000`. Якщо `ConvergenceWarning` виникає, notebook виводить його тип і текст; це дозволяє аналізувати причину, а не замовчувати проблему.

Додатково для Lasso та Elastic Net оцінюється кількість ненульових коефіцієнтів.

Графік: `figures/06_regularization_comparison.png`.

## 11. Висновок

Контрольована шкала ступенів дозволяє побачити перехід від недостатньої складності до перенавчання. Найкраще узагальнення досягається на значно простішому просторі, ніж degree=10. На складному просторі регуляризація порівнюється за CV RMSE, generalization gap і варіативністю, а для Lasso/Elastic Net також за простотою коефіцієнтів.

## 7. Вибір гіперпараметрів регуляризації

Для складного поліноміального простору `degree=10` параметр `alpha` підбирається тільки на навчальній вибірці за однаковою 5-fold CV. Використано логарифмічну сітку `10^-4 ... 10^4`, що охоплює майже відсутню, оптимальну та надмірну регуляризацію. Для Elastic Net перевірено `l1_ratio = 0.2, 0.5, 0.8`. Test set не використовується для зміни діапазону.

Оскільки високостепеневий простір є погано обумовленим для дуже малих `alpha`, у notebook збережено факт `ConvergenceWarning`, якщо він виникає. Попередження не вимикаються; стан збіжності записується у `alpha_search_results.csv`.

## 8. Аналіз ефекту регуляризації

Для Ridge, Lasso та Elastic Net порівнюються train RMSE, CV RMSE і generalization gap. Додатково обчислюється `||w||_2` та кількість ненульових коефіцієнтів. Побудовано регуляризаційні шляхи Ridge і Lasso.

Ridge стискає коефіцієнти, але через L2-штраф зазвичай не обнуляє їх точно. Lasso використовує L1-штраф і тому може формувати розріджений розв'язок; при збільшенні `alpha` кількість ненульових коефіцієнтів зазвичай зменшується. Надмірне стиснення визначається не кількістю нулів саме по собі, а зростанням CV RMSE після області оптимального узагальнення.
## 12. Перевірка стійкості

Для повторної перевірки вибору гіперпараметрів використано п’ять допустимих схем 5-fold KFold з `random_state = 7, 21, 42, 77, 101`. Усі процедури виконуються лише на `train`-частині. У стабілізаційному етапі використано сфокусовану логарифмічну підсітку `alpha = {0.001, 0.01, 0.1, 1, 10}` навколо області, знайденої широким початковим пошуком; для Elastic Net перевірено `l1_ratio = {0.2, 0.5, 0.7, 0.8}`. Це окремий діагностичний етап, а не заміна початкового протоколу.

Результати збережені у `figures/stability_by_scheme.csv` та `figures/stability_summary.csv`. Для кожної моделі наведено діапазон вибраного `alpha`, середній CV RMSE між схемами, стандартне відхилення між схемами, діапазон `||w||₂` та діапазон кількості ненульових коефіцієнтів.

Інтерпретація має бути окремою для кожної величини. Наприклад, якщо CV RMSE змінюється лише на кілька тисячних, це мало щодо масштабу помилки; натомість перехід вибраного `alpha` до іншої області сітки може бути практично значущим. Для Lasso/Elastic Net додатково перевіряється, чи зберігається структура розрідженості.

## 13. Вибір фінальної моделі

Фінальне правило зафіксовано до використання `test set`: спочатку обирається модель з мінімальним середнім CV RMSE; далі застосовується правило однієї стандартної похибки — серед моделей у межах `best CV RMSE + 1 SE` перевага надається простішій моделі. Якщо якість близька, враховуються generalization gap та стабільність гіперпараметрів. Test set не використовується для зміни alpha або вибору сітки.

До порівняльної таблиці включено найкращу нерегуляризовану модель із кривої складності (`degree=2`) та регуляризовані моделі на складному просторі `degree=10`. Детальна таблиця знаходиться у `figures/final_model_comparison.csv`.

За мінімальним CV RMSE серед цих кандидатів перемагає регуляризована модель з близьким значенням похибки, але за правилом 1-SE перевага переходить до **Polynomial LinearRegression degree=2**, оскільки її CV RMSE `0.2682` відрізняється від мінімуму лише в межах однієї стандартної похибки та потребує лише 9 ознак замість 285. Це приклад ситуації, коли невелика різниця метрики не виправдовує істотно більш складний простір. Раніше отримане незалежне test-оцінювання цієї моделі: RMSE близько `0.3228`, R² близько `0.2717`.

Усі графіки й таблиці залишено в `figures/`, а код — у notebook, відповідно до структури, рекомендованої методичкою.


## 11. Фінальне оцінювання

Після завершення вибору модель не змінювалася за test-результатом. Обрана конфігурація `Polynomial LinearRegression, degree=2` була навчена один раз на всій training-вибірці та один раз оцінена на test-вибірці.

| Метрика | Значення |
|---|---:|
| Train RMSE (full train) | 0.249653 |
| Очікуваний CV RMSE | 0.268222 |
| CV SE | 0.020378 |
| Test MAE | **0.256227** |
| Test RMSE | **0.322804** |
| Test R² | **0.271652** |
| Test RMSE − CV RMSE | +0.054582 |

Test RMSE приблизно на 20.3% більша за CV RMSE. Можливі пояснення: мала test-вибірка (`n=30`), випадкове відхилення конкретного split та відмінність розподілу складніших об'єктів у test. Для простої degree=2 моделі адаптивне пристосування до CV не є основним поясненням, але варіативність вибірки повністю виключити не можна.

Після отримання test-результату **модель не змінювалася**. Test set не використовувався для переналаштування alpha, degree або вибору іншої моделі.

## 12. Аудит використання ШІ

Суттєві пропозиції ШІ перевірені у чотирьох аспектах: діагностика перенавчання, формула кількості polynomial features, правило 1-SE та ефект регуляризації. Для кількох тверджень виконано незалежну математичну або методологічну перевірку, а не лише запуск коду.

**Комбінаторна перевірка:** при `p=3,d=2` кількість ознак `C(5,2)-1=9`, що збігається з `PolynomialFeatures`.

**Методологічна перевірка 1-SE:** `0.268222 + 0.020378 = 0.288600`; degree=2 має RMSE `0.268222` і лише 9 ознак, тому підходить під правило і є природним простішим кандидатом.

Повна структурована таблиця аудиту знаходиться в `AI_USAGE.md` і відтворюється останніми клітинками notebook.

## 13. Фінальні висновки

Фінальне незалежне оцінювання показало `MAE=0.2562`, `RMSE=0.3228`, `R²=0.2717`. Test RMSE вища за CV RMSE приблизно на `0.0546`; це зафіксовано як властивість конкретного експерименту, а не використано для післяфактум зміни моделі.

Зафіксоване правило CV + 1-SE підтримує вибір простої polynomial-моделі degree=2: вона використовує лише 9 ознак і дає CV RMSE близьке до найкращого результату.
