# AI_USAGE.md

## Використання генеративного ШІ

Генеративний ШІ використовувався як допоміжний інструмент під час підготовки лабораторної роботи:

1. допоміг структурувати експериментальний протокол відповідно до методичних вимог;
2. допоміг сформулювати перевірювані гіпотези щодо складності, перенавчання та регуляризації;
3. допоміг підготувати шаблон Jupyter Notebook, Pipeline, CV та візуалізацій;
4. допоміг сформулювати опис результатів і README.

Автор самостійно визначає зміст експерименту, перевіряє код, запускає notebook, аналізує результати та відповідає за фінальні висновки. ШІ не використовувався для приховування джерел даних, секретів, API-ключів чи іншої конфіденційної інформації.


## Аудит суттєвих тверджень ШІ

### 1. Діагностика перенавчання
**Поставлена задача:** визначити, чи свідчить зростання складності polynomial model про перенавчання.

**Пропозиція ШІ:** після певного degree train RMSE може продовжувати падати, тоді як CV RMSE і generalization gap зростають; це є ознакою перенавчання.

**Спосіб перевірки:** повний експеримент degree=1..10, таблиця train/CV RMSE, std, SE та generalization gap; окремо learning curves для degree=1 і degree=10.

**Фактичний результат:** для degree=10 train RMSE близька до нуля, а CV RMSE стає дуже великою, тому gap різко зростає.

**Рішення:** прийнято.

**Обґрунтування:** форма кривих і величина gap узгоджуються з ознакою перенавчання.

### 2. Формула кількості поліноміальних ознак
**Поставлена задача:** перевірити безпечність шкали degree.

**Пропозиція ШІ:** для `p` числових ознак і `PolynomialFeatures(degree=d, include_bias=False)` кількість сформованих ознак дорівнює `C(p+d,d)-1`.

**Спосіб перевірки:** незалежний комбінаторний розрахунок та порівняння з фактичним результатом `PolynomialFeatures`.

**Фактичний результат:** для `p=3,d=2` математичний розрахунок і sklearn дають 9.

**Рішення:** прийнято.

**Обґрунтування:** це незалежна математична перевірка, яка не залежить від результату fit.

### 3. Правило фінального вибору за 1-SE
**Поставлена задача:** обрати final model без використання test set.

**Пропозиція ШІ:** спочатку мінімізувати середній CV RMSE, а при близьких результатах обирати простішу модель у межах однієї стандартної похибки.

**Спосіб перевірки:** `best CV RMSE + SE = 0.26822 + 0.02038 = 0.28860`; значення порівняно з CV-результатами кандидатів. Додатково виконано методологічну перевірку, що 1-SE є правилом компромісу між похибкою та складністю і не використовує test set.

**Фактичний результат:** degree=2 має CV RMSE ≈ 0.26822 і лише 9 ознак, тому залишається сильним простим кандидатом.

**Рішення:** прийнято.

**Обґрунтування:** невелика різниця CV RMSE не виправдовує збільшення простору з 9 до 285 ознак.

### 4. Ефект регуляризації
**Поставлена задача:** стабілізувати складний degree=10 простір.

**Пропозиція ШІ:** порівняти Linear Regression, Ridge, Lasso та Elastic Net у тому самому Pipeline, з однаковими folds і метрикою.

**Спосіб перевірки:** однакові `PolynomialFeatures`, `StandardScaler`, CV folds і RMSE; додатково regularization paths, норми коефіцієнтів та кількість ненульових коефіцієнтів.

**Фактичний результат:** нерегуляризована Linear Regression на degree=10 має надзвичайно велике CV RMSE, тоді як регуляризовані моделі істотно стабільніші.

**Рішення:** прийнято з уточненням.

**Обґрунтування:** покращення залежить від alpha; надто сильна регуляризація може знову підвищити CV RMSE.

## 5. Фінальне test-оцінювання

Остаточно обрана `Polynomial LinearRegression, degree=2` після завершення вибору навчається на всій training-вибірці та один раз оцінюється на test set. Отримано `MAE=0.256227`, `RMSE=0.322804`, `R²=0.271652`. Test RMSE вища за CV RMSE `0.268222` на `0.054582`. Після перегляду test результату модель не змінювалася.

## Прозорість
AI допомагав зі структурою експерименту, формулюванням гіпотез, варіантами Pipeline та інтерпретацією. Числові результати перевірялися запуском коду; суттєві математичні та методологічні твердження додатково перевірялися незалежним аналізом. Test set не використовувався для корекції моделі після його перегляду.
