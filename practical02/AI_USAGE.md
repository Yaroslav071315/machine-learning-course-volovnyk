# Використання генеративного ШІ (AI Usage)

У цій практичній роботі генеративні моделі використовувалися для:
1. **Формулювання експериментальної гіпотези:** Допомога у коректному формулюванні наукової гіпотези щодо ефективності ML-моделей порівняно з Baseline.
2. **Обґрунтування метрики:** Генерація аргументації для вибору RMSE як основної метрики з точки зору її математичних властивостей (штраф за великі похибки) та фізичної інтерпретації (сантиметри).
3. **Написання коду ізоляції вибірок:** Створення коду Python для розділення даних (80/20) із фіксацією `random_state` та використанням параметра `stratify` для збереження пропорцій категоріальної ознаки `species` у навчальній та тестовій вибірках.
