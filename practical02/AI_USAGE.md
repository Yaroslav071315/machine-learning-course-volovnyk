# Використання генеративного ШІ (AI Usage)

У цій практичній роботі генеративні моделі використовувалися для:
1. **Формулювання експериментальної гіпотези:** Допомога у коректному формулюванні наукової гіпотези щодо ефективності ML-моделей порівняно з Baseline.
2. **Обґрунтування метрики:** Генерація аргументації для вибору RMSE як основної метрики з точки зору її математичних властивостей (штраф за великі похибки) та фізичної інтерпретації (сантиметри).
3. **Написання коду ізоляції вибірок:** Створення коду Python для розділення даних (80/20) із фіксацією `random_state` та використанням параметра `stratify` для збереження пропорцій категоріальної ознаки `species` у навчальній та тестовій вибірках.
4. **Написання коду для запобігання Data Leakage:** Генерація синтаксично правильного коду для `ColumnTransformer` та `Pipeline`, що гарантує ізольоване навчання параметрів `StandardScaler` виключно на навчальній вибірці.
5. **Побудова Baseline-моделі:** Створення пайплайну з `DummyRegressor` та налаштування функції `cross_validate` для коректного отримання метрики `neg_root_mean_squared_error` з подальшим інвертуванням знака для аналізу.
6. **Формування кандидатних моделей:** Залучення генеративного ШІ для добору та обґрунтування моделей із різними математичними принципами (лінійні з регуляризацією проти деревних ансамблів).
7. **Організація суворої схеми Cross-Validation:** Генерація коду із застосуванням явного об'єкта `KFold(shuffle=True, random_state=42)` для створення гарантовано однакових фолдів для всіх порівнюваних алгоритмів.
8. **Розрахунок та форматування метрик:** Написання циклу обробки результатів `cross_val_score` з розрахунком пофолдових похибок, середнього значення, стандартного відхилення та автоматичного форматування у стандарт $RMSE_{mean} \pm RMSE_{std}$.
9. **Коригування вибору моделі на основі даних:** Залучення ШІ для коректного переаналізу та інтерпретації результатів після отримання фактичних метрик CV, де `Linear Regression` перевершила `Ridge` та `Random Forest`.
10. **Аргументація відсутності регуляризації:** Формулювання наукового обґрунтування, чому класичний OLS (Linear Regression) виявився ефективнішим за Ridge на малорозмірному просторі ознак (4 предиктори).
