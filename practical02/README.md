# Практична робота 2

### 1. Постановка задачі
Задача полягає у прогнозуванні ширини чашолистка (`sepal_width`, у см) квітки ірису на основі її довжини, розмірів пелюсток та біологічного виду. Основна експериментальна гіпотеза: застосування регресійних ML-моделей здатне суттєво зменшити похибку порівняно з наївним прогнозом (Baseline). Головною метрикою обрано RMSE, оскільки вона інтерпретується в одиницях цільової змінної (сантиметрах) і жорстко штрафує за грубі відхилення, що важливо для біометрії.

### 2. Формування вибірок
* Дані розділено на навчальну та тестову вибірки у співвідношенні 80% (`train`) до 20% (`test`).
* Використано фіксований параметр `random_state=42` для забезпечення відтворюваності розбиття.
* Розмір навчальної вибірки: 120 об'єктів. Розмір тестової вибірки: 30 об'єктів.
* Тестова вибірка строго ізольована від усіх процесів прийняття рішень (масштабування, вибір моделі, крос-валідація) для запобігання витоку даних (data leakage).

### (3) Формування вибірок та передобробка (Preprocessing)
* **Поділ даних:** Набір даних розділено на навчальну (80%) та тестову (20%) вибірки із фіксацією `random_state=42` та стратифікацією за видами. Тестова вибірка ізольована і не використовується на етапах передобробки чи крос-валідації.
* **Передобробка:** Для числових ознак застосовано `StandardScaler` (для вирівнювання масштабів перед використанням лінійних моделей з регуляризацією). Для категоріальної ознаки виду використано `OneHotEncoder(drop='first')`.
* **Запобігання Data Leakage:** Усі перетворення об'єднані у `ColumnTransformer` та інтегровані в `Pipeline`. Це гарантує, що параметри масштабування обчислюються виключно на тренувальних фолдах під час крос-валідації.

### (5) Вибір кандидатних моделей та Cross-Validation
Для експерименту обрано три кандидатні моделі різної складності:
1. **Linear Regression** — перевірка наявності простих лінійних залежностей.
2. **Ridge** — лінійна регресія з L2-регуляризацією для компенсації можливої мультиколінеарності.
3. **Random Forest** — ансамблева нелінійна модель для оцінки складних взаємодій ознак.

**Схема крос-валідації:**
Для об'єктивності порівняння використано єдину схему `KFold(n_splits=5, shuffle=True, random_state=42)`. Усі моделі та Baseline оцінювалися на однаковій розбивці фолдів виключно на навчальній вибірці (Test set ізольовано).

### (9) Фінальне оцінювання на тестовій вибірці
Найкраща модель (**Linear Regression**) була навчена на повному масиві тренувальних даних та протестована на відкладеній тестовій вибірці (20% від загального набору).
* **Фінальні метрики:** MAE = 0.1458 , RMSE = 0.1785 , $R^2$ = 0.7787.
* **Порівняння:** У даному випадку значення $RMSE_{test}$ виявилося помітно нижчим за $RMSE_{cv}$. Така ситуація свідчить про те, що модель не перенавчилася (відсутній overfitting), але яскраво демонструє вплив випадковості при розбитті набору даних на тренувальну та тестову вибірки.Оскільки датасет невеликий, до тренувальної вибірки (на якій проводилася крос-валідація), ймовірно, потрапили більш складні для прогнозування або нетипові екземпляри квіток (викиди), що завищило середню помилку $RMSE_{cv}$. Натомість тестова вибірка випадково сформувалася з дуже типових екземплярів, які ідеально описуються знайденою лінійною залежністю, через що помилка на нових даних виявилася значно меншою
