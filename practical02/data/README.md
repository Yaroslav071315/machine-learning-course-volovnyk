# data/

Ця робота **не потребує локального зберігання файлу даних**.

- **Набір даних:** Iris Data Set
- **Джерело:** UCI Machine Learning Repository — https://archive.ics.uci.edu/dataset/53/iris
- **Спосіб отримання:** набір є вбудованим у бібліотеку `scikit-learn` і завантажується безпосередньо в коді без звернення до мережі:

  ```python
  from sklearn.datasets import load_iris
  iris = load_iris(as_frame=True)
  df = iris.frame
  ```

- **Розмір:** 150 об'єктів, 4 числові ознаки + 1 категоріальна ознака (вид рослини).
- **Ліцензія / умови використання:** відкритий навчальний набір даних, вільно розповсюджується для дослідницьких і навчальних цілей.

Оскільки набір невеликий (150 рядків) і вбудований у бібліотеку, зберігати його копію у форматі CSV у репозиторії немає потреби.
